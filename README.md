Student Management System

A console-based Student Management System developed using Java, JDBC, and MySQL.

Technologies Used

- Java
- JDBC (Java Database Connectivity)
- MySQL
- Eclipse IDE

Features

- Add Student
- View All Students
- Search Student by ID
- Update Student Details
- Delete Student
- Exit the Application

Database

Database name: "java_practice"

Table name: "students"

Columns:

- "id" — Student ID
- "name" — Student Name
- "age" — Student Age
- "course" — Student Course

Project Files

- "StudentManagementSystem.java" — Main Java program
- "database.sql" — Database and table creation script

How to Run

1. Install Java JDK.
2. Install MySQL Server.
3. Open the project in Eclipse IDE.
4. Create the database using "database.sql".
5. Add the MySQL Connector/J library to the project.
6. Configure your MySQL username and password in the Java program.
7. Run "StudentManagementSystem.java".
